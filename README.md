# CRET Fundraising Website

A responsive React web application developed for **STL Crisis Response Teens (CRET)**, a youth-led nonprofit organization dedicated to supporting families and communities affected by local and global crises.

**Link:** https://dainicole.github.io/CSE204-Final-Project/
## Overview

This website was developed for **STL Crisis Response Teens (CRET)**, a youth-led nonprofit organization focused on supporting communities affected by local and global crises through fundraising, volunteer service, and charitable initiatives.

The site serves as a digital platform for the organization, allowing visitors to learn about its mission, explore handmade products created for fundraising efforts, and view information about past projects and community impact. The application features a responsive React-based interface, interactive product filtering, detailed product pages, and a mobile-friendly design.

Through this project, I designed and developed a modern web application that helps the organization engage supporters and showcase its fundraising activities online.

## Features

* Responsive user interface built with React
* Product catalog showcasing handmade fundraising items
* Product filtering by:

  * Price
  * Size
  * Sale status
* Individual product detail views
* Organization mission and impact pages
* Interactive UI components and dynamic content
* Mobile-friendly design

## Technologies Used

* React
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite
